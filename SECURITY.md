# Security policy

Please do not report vulnerabilities, credentials, customer information, engineering drawings, or other confidential material in a public issue.

For a private report, use the repository owner's GitHub security contact or private contact channel. Include the affected component, reproduction steps that use synthetic data, impact, and a suggested mitigation when possible.

If a credential has been committed or exposed, rotate or revoke it immediately and then report the commit or file privately. Removing a file in a later commit does not remove it from Git history.
